# Hermes Web Project

A clean, modern web project structure with responsive design and interactive features.

## Features

- Responsive layout using CSS Flexbox
- Interactive JavaScript functionality
- Modern CSS with custom properties (variables)
- Mobile-first design approach

## Structure

```
.
├── index.html      # Main HTML file
├── style.css       # Styles and layout
├── main.js         # JavaScript interactions
└── assets/         # Project assets (to be added)
```

## Usage

Open `index.html` in any modern browser.

## Development

- No build tools required - pure HTML/CSS/JS
- Edit files directly and refresh to see changes
- Consider using a local server for optimal performance
