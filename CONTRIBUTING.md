# Contributing

Contributions are welcome! Please follow these steps:

## 1. Fork the Repository

Have a look at [GitHub's documentation](https://help.github.com/articles/forking-a-repo/) to get a local copy of this project.

## 2. Set up Development Environment

```bash
# Clone your fork
git clone https://github.com/YOUR-USERNAME/Hermes.git

# Navigate into directory
cd Hermes

# Install dependencies
npm install
```

## 3. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

## 4. Make Changes

Write tests for any new functionality. Run `npm test` before submitting.

## 5. Commit Changes

```bash
git commit -m "Add: brief description of what you added"
```

## 6. Push Changes

```bash
git push origin feature/your-feature-name
```

## 7. Submit a Pull Request

Open a PR on the main repository. Include a description of your changes.

# Pull Request Guidelines

- Focus on one change at a time
- Write clean commit messages
- Update documentation if needed
- Build and test locally

# Coding Standards

- Follow the existing code style
- Use meaningful variable names
- Keep functions small and focused
- Write clear, concise comments

# Questions or Issues?

Open an issue with the "bug" or "enhancement" label.
